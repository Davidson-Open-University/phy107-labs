# PHY 107 · General Practical Physics I — Online Lab Notebooks

Davidson Open University Global

These are the ten online lab notebooks for **PHY 107 General Practical Physics I**. Each lab goes with one unit of the Moodle course. Every lab pairs a free **open educational resource (OER) simulation** (PhET, Open Source Physics @ Singapore or Virtual Labs India) with a **Python notebook** where you record, analyse and check your results. You run the notebooks in your web browser with **Google Colab** (free, nothing to install) or offline on your own computer with **Jupyter**.

## What is in each lab

Each lab takes **about an hour** and has four parts:

- **Part A – Explore:** open the linked simulation, follow the steps and read short explanations.
- **Part B – Record and analyse:** enter your readings, fill in the blanks (`...`) and run the **self-check** under each one. ✅ means correct, ❌ gives you a hint, and ⏳ means the blank is not filled yet. The checks never reveal the answer.
- **Part C – Build a tool:** complete a short Python function (for example, a mean-and-uncertainty calculator) and test it.
- **Part D – Apply and reflect:** try the safe home task, use your tools on your own data and answer short reflection questions. This prepares you for the unit lab report.

Run the first code cell (**"Run this cell first"**) before anything else: it sets up the self-checks.

**Honest data:** record what you actually measure. Where a lab gives illustrative data, it is there so you can practise the analysis; your own readings go in the places marked for them.

## How to do a lab in Google Colab

1. Click the **Open in Colab** button for the lab. Sign in with your Google account if asked.
2. Choose **File → Save a copy in GitHub** and save it to **your own** `phy107-labs` repository (or **File → Save a copy in Drive**). Do this first, so your work is saved under your account.
3. Run each code cell in order with **Shift + Enter**. Read the explanation above each cell before you run it.
4. Work through Parts A–D, using the self-checks as you go, then save again.
5. Submit what your tutor asks for in Moodle.

## How to do a lab offline (low data)

1. Install **Anaconda** (or Python + `pip install notebook numpy matplotlib`) once, on Wi-Fi.
2. Download this repository: green **Code** button → **Download ZIP**, then unzip it.
3. Start **Jupyter Notebook**, open the lab from the `notebooks` folder and work through it.
4. Many PhET simulations can also be downloaded once and run offline (see each simulation's page).

## Safety

Home tasks use everyday, safe items only. Never use mains electricity, open flames or hot liquids for these tasks. If in doubt, do the simulation only and ask your tutor.
